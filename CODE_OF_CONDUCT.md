# Codigo De Conduta

Este projeto deve ser um espaco pratico, respeitoso e colaborativo para pessoas que querem melhorar ferramentas de CWL.

## Comportamentos Esperados

- Tratar outras pessoas com respeito.
- Explicar problemas tecnicos com clareza.
- Discordar de ideias sem atacar pessoas.
- Ajudar contribuidores iniciantes quando possivel.
- Manter issues e pull requests focados no projeto.

## Comportamentos Nao Aceitos

- Assedio, insultos ou ataques pessoais.
- Exposicao de dados privados de jogadores ou clas.
- Publicacao de segredos, tokens, senhas ou cookies.
- Conteudo que incentive trapaças, bots, venda de contas ou violacao das regras da Supercell.

## Aplicacao

Mantenedores podem fechar issues, editar discussoes, bloquear usuarios ou recusar contribuicoes que prejudiquem a comunidade ou coloquem o projeto em risco.
